# Normal Chat

Normal Chat is a ChatGPT-style AI web application built with Flask, Gemini AI, and PostgreSQL.

## Features

- AI Chat
- Login and Signup
- Chat History
- New Chat
- Rename and Delete Chats
- Memory
- Web Search
- Weather
- PDF Analysis
- Image Understanding
- Voice Input
- Response Style
- Export Chat
- Copy Chat

## Tech Stack

- Python
- Flask
- Google Gemini API
- PostgreSQL
- HTML
- CSS
- JavaScript
